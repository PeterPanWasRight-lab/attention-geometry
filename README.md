# Attention Geometry Lab

A GitHub Pages-ready static site containing two interactive tutorials:

- `single-head.html` — single-head attention geometry
- `multi-head.html` — two-head attention geometry
- `index.html` — landing page with embedded previews

## Publish with GitHub Pages

Recommended repository name for a personal Pages site:

`PeterPanWasRight-lab.github.io`

Then place these files in the repository root and enable GitHub Pages for the `main` branch / root folder if GitHub has not enabled it automatically.

The site will be available at:

`https://PeterPanWasRight-lab.github.io/`

If you prefer a project Pages site, use any repository name, for example `attention-geometry-lab`, and publish the root of `main`. The URL will normally be:

`https://PeterPanWasRight-lab.github.io/attention-geometry-lab/`
