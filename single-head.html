9. Attention 一页总结

9.1 数学公式版

Q = XWQ,   K = XWK,   V = XWV
S = QKT / √d
A = row-softmax(S)
O = AV
oi = Σj aijvj
  • Q/K 用来计算相关性。
  • A 是每个 query 对所有 value 的权重分配。
  • O 是融合后的新 token 表示。

9.2 几何解释版

  • sij = qi·kj/√d 是缩放点积。
  • aij 决定第 i 个 query 对第 j 个 value 的关注强度。
  • oi 是各个 vj 的加权和，而不是简单挑出某一个 vj。
  • 因为 aij ≥ 0 且 Σjaij = 1，所以 oi 是凸组合，端点位于 V 端点张成的凸包内。

9.3 物理直觉版

  • Q 像“我拿什么特征去提问”。
  • K 像“我暴露什么特征供别人匹配”。
  • V 像“真正被搬运和融合的内容”。
  • Attention 不是简单平均，而是“基于相关性的内容读取与融合”。
